Scrape Workday Jobs to Google Sheets with Apify and n8n

Workday career sites show "Posted 30+ Days Ago" and no salary field. Here is how to pull exact posting dates and parsed salary ranges from selected Workday boards, then keep a clean job log in Google Sheets.

Large employers such as NVIDIA, Adobe and Intel post on Workday. Their career pages are built for candidates, not for tracking. Dates collapse into labels like "Posted Today" or "Posted 30+ Days Ago", and there is no salary column to export. If you follow several Workday employers, checking each board by hand is slow and easy to get wrong.

Scope: this workflow tracks the Workday boards you choose. Source access, filters and row limits decide what each run returns. It is not a complete census of every open job, and a salary appears only when the posting itself publishes one.

What you get per job

The Workday Jobs Scraper reads a full myworkdayjobs.com board URL and returns structured jobs: title, every location, the actual posting date instead of a relative label, seniority and job function from the title, and, where the description contains a pay range, salaryMin, salaryMax, currency and period.

In a real run on NVIDIA's board (10 jobs, 12 October 2026), 8 of 10 postings carried a salary range and 2 did not:

Log it in Google Sheets with n8n

The starter workflow has no hidden steps. A daily trigger starts one Actor run. Before anything is written, n8n checks the run status, the HEALTH and COMPANIES reports and the dataset count. If a response looks incomplete, the workflow stops and leaves your Sheet untouched.

Accepted jobs are upserted by a stable key made from your input and the job ID, so a repeat run updates rows instead of duplicating them. The first run is stored as a baseline; later unseen IDs are logged with a first-seen timestamp. Replaying the workflow logic against the real NVIDIA output above produced 10 baseline rows on the first pass and 0 new IDs on the second.

  1. Create a Jobs tab and paste the header row from the starter.
  2. Import the inactive workflow and add your own Apify and Google credentials.
  3. Paste a full Workday board URL, for example the NVIDIA board, and keep the 10-job limit for the first run.
  4. Run once, inspect HEALTH, COMPANIES and the Sheet, then run again.
  5. Enable the daily schedule only after both manual runs look right.

Limits worth knowing

First-seen time is not publication time. A job is logged when your workflow first sees it, which can be later than the date it was posted. A job missing from a later bounded snapshot is not proof that it closed; the starter keeps old rows and does not detect closures. Workday boards cannot be guessed from a company name, so paste the complete board URL.
